# 🎲 Odd or Even Game (Premium Edition)

A beautifully designed, modern Odd or Even game built using **React**, **Vite**, and **Tailwind CSS**. This version features a premium glassmorphic UI, smooth animations with Framer Motion, and is fully containerized with **Docker**.

## ✨ Features

- 🎮 **Single Player Mode**: Play against a smart (randomly generating) CPU.
- 👥 **Two Player Mode**: Local multiplayer with secret input for Player 1.
- 💎 **Premium UI**: Glassmorphism design with backdrop blur and vibrant gradients.
- 🪄 **Micro-animations**: Smooth transitions and state changes powered by Framer Motion.
- 🐳 **Dockerized**: Easy development setup with a single command.

## 🚀 Getting Started

### Prerequisites

- [Docker](https://www.docker.com/products/docker-desktop) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dragonpilee/oddeven-js.git
   cd oddeven-js
   ```

2. **Run with Docker Compose**:
   ```bash
   docker-compose up --build
   ```

3. **Access the Game**:
   Open your browser and navigate to `http://localhost:5173`.
